# University marks for the technical report

The FAST and NUCES marks were downloaded on 23 November 2026 from the
university's official website:

- https://nu.edu.pk/Content/images/FAST.png
- https://nu.edu.pk/Content/images/NU-logo.jpg
- Brand guidance: https://nu.edu.pk/public/downloads/Guidelines.FAST-NUCES.brand.identity_2024-Oct-21.pdf

These marks identify the institution on an academic course report. They remain
the property of their respective owners. The report renderer prints the FAST
mark in black on white to meet the requested single-ink presentation. The
original downloaded files are preserved here.
